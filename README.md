# .github da LED

Repositório de configuração da organização [LED-CIn-UFPE](https://github.com/LED-CIn-UFPE).

| Caminho | Para que serve |
|---|---|
| `profile/README.md` | Página de apresentação exibida em github.com/LED-CIn-UFPE |
| `assets/` | Banner e logos usados no perfil |
| `.github/ISSUE_TEMPLATE/` | Formulários de issue usados por todos os repositórios da org |
| `.github/pull_request_template.md` | Modelo de descrição de PR padrão |
| `CONTRIBUTING.md` | Como contribuir com os repositórios da LED |
| `CODE_OF_CONDUCT.md` | Código de conduta da comunidade |
| `SECURITY.md` | Como reportar credenciais vazadas ou falhas de segurança |

Os arquivos de comunidade valem para qualquer repositório da organização que não tenha a sua própria versão.
