# Segurança

## Encontrou uma credencial vazada ou uma falha?

Muitos materiais da LED usam serviços de nuvem. Se você encontrar uma chave de acesso, senha, token ou outro dado sensível em algum repositório da organização:

1. **Não abra uma issue pública.**
2. Envie um e-mail para **led@cin.ufpe.br** com o link do arquivo ou commit.
3. Se possível, use o recurso [Report a vulnerability](https://docs.github.com/pt/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) do próprio repositório.

Responderemos o quanto antes e revogaremos a credencial exposta.
