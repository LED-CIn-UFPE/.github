# Como contribuir com a LED

Os repositórios da LED reúnem materiais de aulas, workshops, pesquisas e projetos da liga. Contribuições de ligantes e da comunidade são bem-vindas.

## Encontrou um problema ou tem uma ideia?

Abra uma issue no repositório correspondente usando um dos formulários:

- **Problema em material ou código**, quando algo não funciona como descrito;
- **Sugestão de conteúdo**, para propor temas de encontros, workshops ou pesquisas.

## Enviando uma mudança

1. Ligantes criam uma branch no próprio repositório; quem é de fora da liga faz um fork.
2. Use nomes de branch descritivos, por exemplo `feat/dag-ingestao` ou `fix/readme-setup`.
3. Escreva mensagens de commit curtas, no imperativo, explicando o que muda: `Adiciona DAG de ingestão da API de futebol`.
4. Abra um pull request para a `main` preenchendo o modelo e peça revisão de pelo menos uma pessoa da liga.

## Boas práticas

- Nunca faça commit de credenciais, chaves de nuvem ou arquivos `.env`. Use `.env.example` com valores fictícios.
- Mantenha o README do repositório atualizado com pré-requisitos e passo a passo de execução.
- Prefira dados públicos ou sintéticos nos exemplos.

Ao participar, você concorda com o nosso [Código de Conduta](CODE_OF_CONDUCT.md).
